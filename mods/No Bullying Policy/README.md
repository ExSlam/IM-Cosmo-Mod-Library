# No Bullying Policy

`No Bullying Policy` adds a policy setting that can disable bullying while leaving vanilla behavior available through the default option.

## Player-facing behavior

- Adds `Default` and `No Bullying` policy choices.
- `No Bullying` prevents new bullying targets, ends ongoing bullying, and skips the normal weekly bullying penalties.
- `Default` leaves the base game's bullying behavior unchanged.

## Requirements

- Requires IM-HarmonyIntegration.
- Requires Mod Localization System.

## Build

Project file:

- `mods/No Bullying Policy/No Bullying Policy.csproj`

Example command:

- `dotnet build "mods/No Bullying Policy/No Bullying Policy.csproj" -c Release`
