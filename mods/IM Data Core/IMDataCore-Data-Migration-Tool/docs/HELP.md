# In-program Help

Data Migration Tool 1.10.0 adds a plain-language Help window for regular users.

The main Help button opens the full guide. Contextual Help buttons are also available from Bulk contamination scan, Bulk convert, Resolve match, and Repair branch contamination; those buttons open the same guide near the relevant section.

The guide covers:

- what Data Migration Tool does and what to prepare first;
- individual save migration;
- finding a vanilla save from an old IMDataCore database;
- what **Validate only** does and does not prove;
- branch contamination repair;
- bulk contamination scanning;
- bulk conversion planning and execution;
- resolving weak, ambiguous, or missing save matches;
- future-tail truncation when IMDataCore saved after the vanilla slot;
- optional Recycle Bin cleanup;
- common bulk-plan statuses;
- logs and basic troubleshooting.

The Help popup uses one shared horizontal/vertical scroll surface, matching the popup accessibility rule used elsewhere in Data Migration Tool. It is localized in every GUI language shipped with the tool.
