[h1]IM Data Core[/h1]
A shared data and history backend for Idol Manager mods in the Cosmo Mod Library, including Idol Career Diary and Monthly Ledger mods.

IM Data Core is primarily a framework dependency. Other mods use it to keep save-scoped custom state, historical timeline events, and an exact money ledger without modifying Idol Manager's vanilla save JSON.

[h1]Version 3.7.5[/h1]
[list]
[*] JSON-native sidecar storage
[*] SHA-256 content-fingerprinted exact save checkpoints
[*] Exact per-save-file persistence and rollback checkpoints
[*] Anchored adoption of existing vanilla careers before explicit IMDC-only flushes
[*] Namespaced custom JSON for consumer mods
[*] Shared historical event ledger
[*] Exact cash transaction history
[*] Transactional delta-journal persistence and backup recovery
[/list]

The current save-data layout is IMDC sidecar format 6 with transactional journal format 3. These format numbers are separate from the mod version.

When a vanilla save is deleted, IM Data Core preserves its mirrored supplemental directory instead of deleting it. This retained history is intended to support later career-diary export tooling.

[h1]Upgrading from an older IM Data Core version[/h1]
If you want to keep data saved in an old IMDataCore format, you must convert it before loading that save with this version. The mod does not convert old data automatically.

Close Idol Manager and run [b]IMDataCore Data Migration Tool.exe[/b] from the included [code]IMDataCore Data Migration Tool winx64[/code] folder. The tool supports legacy IMDataCore [b]1.0.0-1.3.0[/b] database and fallback files. Select the matching Idol Manager save and old IMDataCore file, use [b]Validate only[/b], then [b]Migrate copy[/b]. Keep a backup of the original files until you have checked the result. The tool's [b]Help[/b] button explains the steps.

Data already using sidecar format 6 and journal format 3 does not need this conversion. The tool is not a converter for every older sidecar format.

[h1]For mod authors[/h1]
Use the public [code]IMDataCoreApi[/code] surface. The included documentation and template mod cover namespace registration, custom JSON state, custom events, history reads, and explicit flushes.
