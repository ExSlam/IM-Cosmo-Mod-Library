[b]Save n Load Fixes[/b]
作者：Cosmo

Save n Load Fixes は、保存や読み込みの後に Idol Manager がゲーム進行を忘れたり、失ったり、誤って処理したりする不具合を修正します。また、非常に大きな所持金、ファン数、研究値などが不正な値や負の値になる大数値の問題も修正します。

[b]修正内容[/b]

[list]
[*] セーブ処理を正しい順序で完了させ、完了していないセーブの読み込みを防ぎます。
[*] 「保存して終了」で、ゲームを閉じたりメインメニューへ戻ったりする前にセーブ完了を待つようにします。
[*] トレーニング、ビジネス、アクティビティ、人間関係、卒業、イベント、アワード、チュートリアル、SNS メッセージなど、進行中のゲーム状態をより多く保持します。
[*] 古いセーブデータを読み込む際の複数の問題を修正します。
[*] 所持金、ファン、ローン、ビジネス収入、劇場・カフェ収入、研究値などの大数値計算を修正します。
[*] セーブシステムの修復中に見つかった、いくつかの小さなバニラ版の不具合を修正します。
[*] セーブの開始、完了、失敗時に簡単な通知を表示します。
[/list]

[b]必須項目[/b]

[list]
[*] IM-HarmonyIntegration Plugin: https://steamcommunity.com/sharedfiles/filedetails/?id=3102983863
[/list]

[b]ローダー互換性[/b]

Tel のオリジナル版 IM-HarmonyIntegration（バージョン 1.1 を含む）に対応しています。設定を開き直したりキャンセルしたりしてローダーがこの Mod を再適用しても、それだけで修復済みのセーブチェックが失敗することはありません。

[url=https://github.com/ExSlam/IM-HarmonyIntegration]Cosmo 更新版 HarmonyIntegration[/url] は不要なパッチの再読み込みを避けるため推奨されますが、Save n Load Fixes の必須要件ではありません。この更新でセーブ形式は変更されません。

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

Save Write Ordering Fix は通常、Save n Load Fixes には[b]必要ありません[/b]。

[b]CreateAnAlbum[/b] と Save n Load Fixes を併用する場合は、Save Write Ordering Fix もインストールしてください。CreateAnAlbum 独自のセーブ処理が Save n Load Fixes と競合するのを防ぎます。
