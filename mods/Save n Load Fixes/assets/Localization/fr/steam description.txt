[b]Save n Load Fixes[/b]
Par Cosmo

Save n Load Fixes corrige des bugs qui peuvent faire oublier, perdre ou mal gérer la progression d'Idol Manager après une sauvegarde ou un chargement. Il corrige aussi des problèmes de très grands nombres qui peuvent rendre incorrects ou négatifs les totaux très élevés d'argent, de fans, de recherche et autres valeurs.

[b]Ce que le mod corrige[/b]

[list]
[*] Termine les sauvegardes dans le bon ordre et empêche le chargement d'une sauvegarde inachevée.
[*] Fait attendre la fin de la sauvegarde à « Sauvegarder et quitter » avant de fermer le jeu ou de revenir au menu principal.
[*] Préserve davantage d'états de jeu en cours, notamment l'entraînement, les contrats professionnels, les activités, les relations, les remises de diplôme, les événements, les récompenses, les tutoriels et les messages SNS.
[*] Corrige plusieurs problèmes lors du chargement d'anciennes sauvegardes.
[*] Corrige les calculs de très grands nombres pour l'argent, les fans, les prêts, les revenus professionnels, les revenus du théâtre et du café, la recherche et d'autres totaux.
[*] Corrige plusieurs petits bugs du jeu de base découverts pendant la réparation du système de sauvegarde.
[*] Affiche des notifications simples au début, à la fin ou en cas d'échec d'une sauvegarde.
[/list]

[b]Prérequis[/b]

[list]
[*] IM-HarmonyIntegration Plugin: https://steamcommunity.com/sharedfiles/filedetails/?id=3102983863
[/list]

[b]Compatibilité du chargeur[/b]

Compatible avec l'IM-HarmonyIntegration d'origine de Tel, y compris la version 1.1. Rouvrir ou annuler les paramètres ne fait plus échouer les contrôles de sauvegarde réparés simplement parce que le chargeur réapplique le mod.

[url=https://github.com/ExSlam/IM-HarmonyIntegration]La version mise à jour de HarmonyIntegration par Cosmo[/url] est recommandée, car elle évite les rechargements inutiles de correctifs, mais elle n'est pas requise par Save n Load Fixes. Cette mise à jour ne modifie pas le format de vos sauvegardes.

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

Save Write Ordering Fix n'est [b]normalement pas[/b] requis par Save n Load Fixes.

Si vous utilisez [b]CreateAnAlbum[/b] avec Save n Load Fixes, installez également Save Write Ordering Fix. Cela empêche le système de sauvegarde propre à CreateAnAlbum d'entrer en conflit avec Save n Load Fixes.
