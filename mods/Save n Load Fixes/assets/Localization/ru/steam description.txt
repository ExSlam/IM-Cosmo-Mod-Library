[b]Save n Load Fixes[/b]
Автор: Cosmo

Save n Load Fixes исправляет ошибки, из-за которых Idol Manager может забывать, терять или неправильно обрабатывать игровой прогресс после сохранения и загрузки. Мод также исправляет проблемы с очень большими числами, из-за которых крупные значения денег, фанатов, исследований и других показателей могут становиться неверными или отрицательными.

[b]Что исправляет мод[/b]

[list]
[*] Завершает сохранения в правильном порядке и не позволяет загрузить незавершённое сохранение.
[*] Заставляет «Сохранить и выйти» дождаться окончания сохранения перед закрытием игры или возвратом в главное меню.
[*] Сохраняет больше текущего состояния игры, включая тренировки, деловые задания, активности, отношения, выпуски, события, награды, обучение и сообщения SNS.
[*] Исправляет несколько проблем при загрузке старых сохранений.
[*] Исправляет вычисления с большими числами для денег, фанатов, кредитов, доходов бизнеса, театра и кафе, исследований и других показателей.
[*] Исправляет несколько небольших ошибок базовой игры, обнаруженных при ремонте системы сохранений.
[*] Показывает простые уведомления о начале, завершении или сбое сохранения.
[/list]

[b]Требование[/b]

[list]
[*] IM-HarmonyIntegration Plugin: https://steamcommunity.com/sharedfiles/filedetails/?id=3102983863
[/list]

[b]Совместимость загрузчика[/b]

Работает с оригинальным IM-HarmonyIntegration от Tel, включая версию 1.1. Повторное открытие или отмена настроек больше не приводит к сбою исправленных проверок сохранения только потому, что загрузчик повторно применяет мод.

[url=https://github.com/ExSlam/IM-HarmonyIntegration]Обновлённый HarmonyIntegration от Cosmo[/url] рекомендуется, поскольку он избегает ненужной повторной загрузки патчей, но не является обязательным для Save n Load Fixes. Это обновление не меняет формат сохранений.

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

Save Write Ordering Fix обычно [b]не требуется[/b] для Save n Load Fixes.

Если вы используете [b]CreateAnAlbum[/b] вместе с Save n Load Fixes, установите также Save Write Ordering Fix. Это предотвращает конфликт собственного механизма сохранения CreateAnAlbum с Save n Load Fixes.
