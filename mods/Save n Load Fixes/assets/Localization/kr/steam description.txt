[b]Save n Load Fixes[/b]
제작: Cosmo

Save n Load Fixes는 저장하거나 불러온 뒤 Idol Manager가 게임 진행 상황을 잊거나 잃거나 잘못 처리하게 만드는 문제를 수정합니다. 또한 매우 큰 자금, 팬, 연구 및 기타 수치가 잘못되거나 음수가 되는 큰 수치 계산 문제도 수정합니다.

[b]수정 내용[/b]

[list]
[*] 저장이 올바른 순서로 완료되도록 하고, 아직 끝나지 않은 저장 파일을 불러오지 못하게 합니다.
[*] 저장 후 종료 시 게임을 닫거나 메인 메뉴로 돌아가기 전에 저장이 끝날 때까지 기다리도록 합니다.
[*] 트레이닝, 비즈니스 업무, 활동, 관계, 졸업, 이벤트, 시상, 튜토리얼, SNS 메시지 등 진행 중인 게임 상태를 더 많이 보존합니다.
[*] 오래된 저장 파일을 불러올 때 발생하는 여러 문제를 수정합니다.
[*] 자금, 팬, 대출, 비즈니스 수입, 극장 및 카페 수입, 연구 등 여러 합계의 큰 수치 계산을 수정합니다.
[*] 저장 시스템을 수정하는 과정에서 발견된 여러 작은 기본 게임 버그를 수정합니다.
[*] 저장 시작, 완료 또는 실패 시 간단한 알림을 표시합니다.
[/list]

[b]로더 호환성[/b]

Tel의 원본 IM-HarmonyIntegration과 호환되며 버전 1.1도 포함됩니다. 설정을 다시 열거나 취소하여 로더가 모드를 다시 적용하더라도, 그 이유만으로 수정된 저장 검사 기능이 실패하지 않습니다.

[url=https://github.com/ExSlam/IM-HarmonyIntegration]Cosmo의 업데이트된 HarmonyIntegration[/url]은 불필요한 패치 재로딩을 피하므로 권장되지만 Save n Load Fixes의 필수 요소는 아닙니다. 이 업데이트는 저장 형식을 변경하지 않습니다.

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

Save Write Ordering Fix는 일반적으로 Save n Load Fixes에 [b]필요하지 않습니다[/b].

[b]CreateAnAlbum[/b]을 Save n Load Fixes와 함께 사용한다면 Save Write Ordering Fix도 설치하세요. CreateAnAlbum의 자체 저장 처리가 Save n Load Fixes와 충돌하는 것을 방지합니다.
