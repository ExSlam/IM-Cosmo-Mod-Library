[b]Save n Load Fixes[/b]
Por Cosmo

Save n Load Fixes corrige bugs que podem fazer o Idol Manager esquecer, perder ou tratar incorretamente o progresso do jogo depois de salvar e carregar. Também corrige problemas com números muito grandes que podem fazer valores extremamente altos de dinheiro, fãs, pesquisa e outros totais ficarem incorretos ou negativos.

[b]O que ele corrige[/b]

[list]
[*] Faz os salvamentos terminarem na ordem correta e impede o carregamento de um salvamento ainda incompleto.
[*] Faz a opção Salvar e Sair esperar o salvamento terminar antes de fechar o jogo ou voltar ao menu principal.
[*] Preserva mais estados em andamento do jogo, incluindo treinamento, trabalhos de negócios, atividades, relacionamentos, formaturas, eventos, prêmios, tutoriais e mensagens de SNS.
[*] Corrige vários problemas ao carregar salvamentos antigos.
[*] Corrige cálculos com números muito grandes para dinheiro, fãs, empréstimos, renda de negócios, renda do teatro e do café, pesquisa e outros totais.
[*] Corrige vários bugs menores do jogo base encontrados durante o reparo do sistema de salvamento.
[*] Exibe notificações simples quando o salvamento começa, termina ou falha.
[/list]

[b]Requisito[/b]

[list]
[*] IM-HarmonyIntegration Plugin: https://steamcommunity.com/sharedfiles/filedetails/?id=3102983863
[/list]

[b]Compatibilidade do carregador[/b]

Funciona com o IM-HarmonyIntegration original do Tel, incluindo a versão 1.1. Reabrir ou cancelar as configurações não faz mais as verificações de salvamento corrigidas falharem apenas porque o carregador reaplica o mod.

[url=https://github.com/ExSlam/IM-HarmonyIntegration]O HarmonyIntegration atualizado do Cosmo[/url] é recomendado porque evita recarregamentos desnecessários de patches, mas não é obrigatório para o Save n Load Fixes. Esta atualização não altera o formato dos seus salvamentos.

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

O Save Write Ordering Fix [b]normalmente não[/b] é necessário para o Save n Load Fixes.

Se você usa [b]CreateAnAlbum[/b] junto com Save n Load Fixes, instale também o Save Write Ordering Fix. Isso evita que o próprio sistema de salvamento do CreateAnAlbum entre em conflito com o Save n Load Fixes.
