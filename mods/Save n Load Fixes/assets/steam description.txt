[b]Save n Load Fixes[/b]

Save n Load Fixes fixes bugs that can make Idol Manager forget, lose, or mishandle game progress after saving and loading. It also fixes large-number problems that can make very high money, fan, research, and other totals become incorrect or negative.

[b]What it fixes[/b]

[list]
[*] Makes saves finish in the correct order and prevents loading an unfinished save.
[*] Makes Save & Exit wait for saving to finish before closing the game or returning to the main menu.
[*] Preserves more in-progress game state, including training, business jobs, activities, relationships, graduations, events, awards, tutorials, and SNS messages.
[*] Fixes several problems when loading older saves.
[*] Fixes large-number calculations for money, fans, loans, business income, theater and café income, research, and other totals.
[*] Fixes several smaller vanilla bugs found while repairing the save system.
[*] Shows simple notifications when saving starts, finishes, or fails.
[/list]

[b]Requirement[/b]

[list]
[*] IM-HarmonyIntegration Plugin: https://steamcommunity.com/sharedfiles/filedetails/?id=3102983863
[/list]

[b]Loader compatibility[/b]

Works with Tel's original IM-HarmonyIntegration, including version 1.1. Reopening or cancelling settings no longer makes the repaired save checks fail just because the loader reapplies the mod.

[url=https://github.com/ui3TD/IM-HarmonyIntegration/releases/tag/1.2.0]updated HarmonyIntegration[/url] is recommended as replacement for the outdated Integration 1.1.0 in your bepinex plugins folder, but it is not required by Save n Load Fixes. This update does not change your save format.

[b]Save Write Ordering Fix / CreateAnAlbum[/b]

Save Write Ordering Fix is [b]not[/b] normally required by Save n Load Fixes.

If you use [b]CreateAnAlbum[/b] together with Save n Load Fixes, install Save Write Ordering Fix too. This prevents CreateAnAlbum's own save handling from conflicting with Save n Load Fixes.
